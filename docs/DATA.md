# Данные: что хранится и сколько живёт

Базы нет. Всё состояние — обычные файлы в каталоге `./data`, построчный JSON или один объект.
Каталог в git не попадает и в образ не копируется: в контейнере на него нужно смонтировать том,
иначе данные исчезнут при пересборке.

| Файл | Формат | Что внутри | Срок жизни |
|---|---|---|---|
| `events.jsonl` | строка на событие | Обезличенная телеметрия: визит, поиск, открытие канала, промах. Ключ — анонимный id браузера. | 30 дней, чистится автоматически |
| `usage.json` | объект по дням | Счётчики действий: поиски, подборки, контакты, обращения к модели. | бессрочно |
| `hits.json` | объект по дням | Счётчик поисков по дням. | бессрочно |
| `misses.jsonl` | строка на запись | Нажатия «пусто / не то»: текст запроса, канал, комментарий. | бессрочно |
| `chat.jsonl` | строка на сообщение | Сообщения внутреннего анонимного чата. | 24 часа, удаляются сами |
| `feedback.jsonl` | строка на запись | Сообщения обратной связи и почта, если её указали. | бессрочно |
| `salt.key` | строка | Соль для необратимого хэша IP. Создаётся при первом запуске. | бессрочно |

## Персональные данные

**Кандидатов X-Raya не хранит.** Инструмент собирает поисковые запросы и ссылки; выдача
открывается прямо в браузере рекрутера, сервер её не видит и не сохраняет. Контакты,
полученные через открытие, отдаются в браузер и на диск не пишутся — в лог уходит только сам
факт открытия, без содержимого.

**Пользователей тоже нет.** В этой версии нет регистрации, аккаунтов, паролей и сессий.
Единственное, что связано с человеком, — анонимный идентификатор браузера в localStorage,
по которому считается статистика.

Ключом при подсчёте служит случайный идентификатор из localStorage, а не IP: за одним
сетевым адресом может находиться много пользователей, и по IP они считались бы как один.
Если идентификатор не передан (старая вкладка, бот), берётся необратимый хэш IP с солью —
восстановить адрес из него нельзя.

Что попадает в лог событий: тип события, канал, метка источника перехода, идентификатор
браузера, время. Текст запроса — только в `misses.jsonl` и только когда рекрутер сам нажал
«пусто / не то», чтобы можно было разобрать промах движка.

## Перенос

Состояние переносится копированием каталога `data`. Никаких миграций, дампов и внешних
хранилищ. Если состояние не нужно — каталог можно просто не переносить, приложение создаст
его заново при первом запуске.
