# Серверные интерфейсы

> **Тестовая версия.** Эндпоинты писались под собственный интерфейс X-Raya.
> Описание отражает текущее состояние кода.

---

## Эндпоинты

Все ответы — JSON, все запросы — `POST` с телом JSON, если не указано иное.

| Эндпоинт | Назначение | Требует ключ провайдера |
|---|---|---|
| `POST /api/ai` | разбор свободного запроса моделью | да |
| `POST /api/candy` | сборка JSON-подборки по описанию | да |
| `GET · POST /api/candy/gate` | заперта ли вкладка подборок; ввод пароля | нет |
| `POST /api/count` | размер выдачи запроса в Google | да |
| `POST /api/contact` | контакты по ссылке, почте или телефону | да |
| `POST /api/nick` | проверка ника на шести площадках | нет |
| `POST /api/ev` · `/api/hit` · `/api/miss` | обезличенная телеметрия | нет |
| `POST /api/feedback` | сообщение владельцу | нет |
| `GET /api/stats?token=` | сводка метрик | пароль статистики |
| `GET /api/ai/diag?token=` | диагностика пути к модели | пароль статистики |

### `POST /api/candy`

```jsonc
// запрос
{
  "task": "бывшие сотрудники, продуктовые аналитики, уволились без негатива",
  "pw":   "<пароль вкладки, если задан CANDY_PASSWORD>",
  "refine": "",   // необязательно: уточнение к предыдущему ответу
  "fix":    "",   // необязательно: ошибки валидатора для починки
  "prev":   ""    // необязательно: предыдущий ответ модели
}

// ответ
{
  "text": "## JSON\n```json\n{...}\n```\n\n## Что понял\n...",
  "cut": false    // true = ответ модели оборвался по лимиту
}
```

Ответ приходит текстом в markdown: блок с JSON и пояснения к нему. Разбор и валидация
выполняются на клиенте, функциями `podClean`, `podJsonSrc` и `podCheck` в `index.html`.

### `POST /api/ai` — разбор запроса

```jsonc
// запрос
{ "system": "<инструкция>", "user": "<текст рекрутера>" }
// ответ
{ "text": "<ответ модели строкой>" }
```

Тонкий прокси: подставляет ключ, модель и параметры, обращается к OpenAI-совместимому
провайдеру. Промпт приходит с клиента, инструкция для разбора запроса лежит в `index.html`
в константе `SYS_INTERPRET`.

### Частота запросов

Считаются по IP на скользящий час, значения задаются переменными окружения:
600 запросов к модели, 200 подборок, 200 проверок ника, 30 открытий контактов.
Потолки заданы с запасом: за одним сетевым адресом может работать много пользователей.
