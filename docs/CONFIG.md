# Переменные окружения

Обязательных нет ни одной. Без ключей работает базовый сценарий: разбор запроса словарями и
генерация всех поисковых запросов. Каждая функция включается своей переменной.

## Модель

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `AI_BASE_URL` | — | Адрес OpenAI-совместимого провайдера. Путь `/chat/completions` дописывается сам. |
| `AI_API_KEY` | — | Ключ этого провайдера. Вместе с `AI_BASE_URL` включает разбор запроса и подборки. |
| `AI_MODEL` | `openai/gpt-4o-mini` | Имя модели у провайдера. |
| `AI_TEMPERATURE` | `0.4` | Не отправляется «думающим» моделям — они его не принимают. |
| `AI_REASONING` | `minimal` | `reasoning_effort` для gpt-5 и o-серии. |
| `AI_MAX_TOKENS` | 800 для обычных моделей | Лимит ответа. Для думающих моделей по умолчанию не задаётся. |
| `AI_MAX_TOKENS_CANDY` | `32000` | Лимит ответа для подборок отдельно: он больше, потому что промпт со схемой ATS объёмный. |
| `AI_RELAY_URL` | — | Запасной путь: ретранслятор, если провайдер режет адрес сервера. Игнорируется, когда задан `AI_BASE_URL`. |
| `RELAY_SECRET` | — | Общий секрет с ретранслятором. |
| `OPENROUTER_API_KEY` | — | Третий запасной путь, напрямую в OpenRouter. |

Порядок выбора: прямой провайдер → ретранслятор → OpenRouter. Диагностика пути — на
`/api/ai/diag?token=<пароль статистики>`: он показывает, куда уходит запрос, что ответил
провайдер и подробности последней пустой выдачи модели.

## Подборки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `CANDY_PASSWORD` | — | Пароль на вкладку подборок. Не задан = вкладка открыта всем. Проверяется и на API, а не только в интерфейсе. |
| `CANDY_HOURLY_LIMIT` | `200` | Подборок в час с одного адреса. |

## Внешние сервисы

| Переменная | Что включает |
|---|---|
| `SERPER_KEY` | Проверку размера выдачи в Google через serper.dev. Приоритетнее CSE. |
| `GOOGLE_CSE_KEY` + `GOOGLE_CSE_CX` | То же самое через Google Custom Search, если нет Serper. |
| `SIGNALHIRE_KEY` | Открытие контактов по ссылке, почте или телефону. Синоним — `SIGNALHIRE_API`. |
| `SH_API_URL` | Переопределение адреса SignalHire, если нужен свой контур. |
| `TG_BOT_TOKEN` + `TG_CHAT_ID` | Уведомление в Telegram о сообщениях обратной связи. |

## Служебное

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт сервера. |
| `STATS_TOKEN` | — | Пароль к `/stats` и `/api/ai/diag`. Не задан = страница метрик отключена. |
| `AI_HOURLY_LIMIT` | `600` | Обращений к модели в час с одного адреса. |
| `HASH_SALT` | генерируется | Соль для необратимого хэша IP. Если не задана, создаётся при первом запуске и лежит в `data/salt.key`. |

Лимиты считаются по IP. Потолки заданы с запасом, потому что за одним сетевым адресом может
работать много пользователей одновременно.

## Пути к файлам

`USAGE_FILE`, `EVENTS_FILE`, `HITS_FILE`, `MISS_FILE`, `CHAT_FILE`, `FEEDBACK_FILE`, `SALT_FILE`
— переопределяют расположение соответствующих файлов состояния. По умолчанию всё в `./data`.
См. [DATA.md](DATA.md).
