# Архитектура

## Из чего состоит

```
браузер (index.html)                    сервер (server.js)              внешние сервисы
─────────────────────                   ──────────────────              ────────────────
консоль запроса                         роутер, 22 маршрута
справочники: города,        ──────►     /api/ai        ──────────────►  провайдер модели
роли, стек, грейды                      /api/candy     ──────────────►  провайдер модели
разбор фразы                            /api/count     ──────────────►  Serper · Google CSE
генерация ~30 запросов                  /api/contact   ──────────────►  SignalHire
дека результатов                        /api/nick      ──────────────►  6 площадок
валидатор JSON-подборок                 /api/ev,hit,miss ────────────►  ./data
                                        /api/stats
        │
        └── клик по каналу ────────────────────────────────────────────►  Google · LinkedIn · hh.ru
                                        (напрямую из браузера, сервер не участвует)
```

Существенная деталь: **выдачу по каналам сервер не видит**. Рекрутер кликает по карточке, и
браузер открывает площадку напрямую. Сервер узнаёт только сам факт клика, и то обезличенно.

## Почему так

**Ноль зависимостей.** Ни одного npm-пакета, ни сборки, ни транспиляции. Аудит и перенос
сводятся к чтению двух файлов.

**Логика на клиенте.** Разбор запроса и генерация ссылок происходят в браузере, потому что
им не нужен ни сервер, ни сеть: справочники зашиты в страницу. Отклик мгновенный, а сервер
нужен только там, где требуется чужой ключ.

**Ключи только на сервере.** Любой вызов платного сервиса идёт через свой эндпоинт, который
подставляет ключ из переменных окружения. В браузер ключи не попадают ни при каких условиях.

**Файлы вместо базы.** Объёмы маленькие, запись редкая, состояние переносится копированием
каталога.

## Карта файлов

| Файл | Строк | Что там |
|---|---|---|
| `index.html` | ~3400 | Справочники, разбор запроса, генерация каналов, дека, фильтры, AI-слой, валидатор подборок, чат |
| `server.js` | ~1080 | Роутер, прокси к модели, подборки, проверка выдачи, контакты, ники, телеметрия, метрики |
| `stats.html` | ~300 | Панель метрик: воронка, возвраты, каналы, промахи |
| `help.html` | ~110 | Справка по интерфейсу |
| `privacy.html` | ~60 | Политика обработки данных |
| `candy-json/` | ~1900 | Движок подборок: разбор запроса по полям, сборка фильтра, сверка со схемой, замеры качества |
| `candy-kb/` | 14 файлов | Выгруженные справочники Candy: поля модели, реестр операторов, специализации, коды состояний и причин |
| `candy-prompt.md` | ~530 | Запасной путь подборок: те же правила языка одним промптом |

`index.html` разделён комментариями-заголовками: `ДАННЫЕ`, `ПАРСИНГ`, `ГЕНЕРАЦИЯ`,
`ПОДБОРКИ CANDY`, `РЕНДЕР`, `ФИЛЬТРЫ`, `AI-СЛОЙ`.
