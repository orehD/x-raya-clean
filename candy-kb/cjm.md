# CJM рекрутера/сорсера — холодный поиск по базе (X-Raya + Candy)

Источник: «Процесс рекрутмента (CJM).pdf» (от Алисы/Димы, сентябрь 2026).
Единый сквозной флоу всех версий: Поиск Candy → кнопка «Помочь с составлением запроса» →
переход на X-Raya → рекрутер вводит критерии → **X-Raya уточняет запрос (диалог)** →
рекрутер отвечает → X-Raya выдаёт результат → рекрутер либо согласен, либо доуточняет (цикл).

## Версия 1 — релиз до 30 сентября 2026 (MVP)
Результат: **JSON + объяснение, из каких источников взяты данные**.
Дальше рекрутер: копирует JSON и вставляет в поиск сам, ЛИБО (если возможно) кнопка
«Применить» — сервис сам вставляет JSON в поиск, рекрутер видит только конечную выдачу.

## Версия 2 — до 30 сентября, если успеем
V1 + X-Raya **предлагает создать подборку**, если запрос регулярный
(обращается в хендбук по API для создания).

## Версия 3 — после 30 сентября
V2 + результат может быть **JSON и/или URL с указанием критериев**, из которых
модель собрала запрос (интеграция с комбинируемыми критериями Candy).

## Мэппинг на движок candy-json
- «X-Raya уточняет запрос» → status:'clarify' + questions (есть; нужен диалоговый цикл
  ответы→пересборка спеки — приоритет №1 для V1)
- «объясняет, из каких источников взяла данные» → explain + таблица проверки (есть)
- «Применить» / вставка в поиск → API-интеграция с фронтом Candy (обсуждать с Колей-тимлидом)
- «предлагает создать подборку» (V2) → API хендбука (галочка «доступ по API» у Алисы)
- «URL с критериями» (V3) → ждёт релиза доп. критериев Candy (конец сентября)
