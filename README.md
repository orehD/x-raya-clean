# X-Raya

Инструмент сорсинга: рекрутер описывает, кого ищет, обычными словами — получает готовые
поисковые запросы по трём десяткам каналов и JSON-подборку для внутренней базы кандидатов.

> ### Тестовая версия
> Функциональность в проработке, интерфейсы не стабилизированы. Документация отражает
> текущее состояние кода.

## Что оно делает

**Поиск людей.** Рекрутер пишет «сеньор python разработчик Москва Django». X-Raya разбирает
фразу на роль, стек, город и грейд, после чего собирает около трёх десятков готовых запросов:
X-Ray по Google для LinkedIn, нативный язык hh.ru, параметрические ссылки Habr Career и GitHub,
профильные площадки под конкретную роль. Каждый запрос открывается одним кликом или копируется.

**Разбор вакансии.** Вместо описания роли можно вставить текст вакансии целиком — требования
разложатся по фильтрам сами, обязательное отделится от желательного.

**Подборки для внутренней базы.** Описание словами превращается в JSON-фильтр сохранённой
подборки ATS. Синтаксис проверяется до выдачи: часть ошибок база не отвергает, а молча
возвращает пустой результат, и валидатор ловит именно их.

**Контакты и проверка выдачи.** Открытие почты и телефона по профилю, проверка ника на шести
площадках, подсчёт размера выдачи в Google — всё через сервер, чтобы ключи не попадали в браузер.

## Состав

```
server.js          весь бэкенд, ~1080 строк, ноль зависимостей
index.html         весь фронтенд: справочники, разбор, генерация запросов, интерфейс
stats.html         внутренняя панель метрик, закрыта паролем
help.html          справка по интерфейсу для рекрутеров
privacy.html       политика обработки данных
candy-prompt.md    схема полей и правила языка подборок ATS
fonts/             локальные шрифты, внешних CDN нет
docs/              документация
```

Вся логика сборки поисковых запросов живёт в браузере. Сервер нужен там, где требуется чужой
ключ или запись на диск, — и больше нигде.

## Устройство

Зависимостей нет: ни сборки, ни `node_modules`, ни транспиляции.

Фронтенд — один файл `index.html`, разделённый комментариями-заголовками: данные, парсинг,
генерация, рендер, фильтры, AI-слой.

Справочники городов, технологий, грейдов и ролей — константы в `index.html`. Отсюда мгновенный
отклик без сети и то, что расширение словаря является правкой кода.

Модель необязательна: она включается на промахах словаря и в подборках, остальное работает
детерминированно.
