# X-Raya

Инструмент сорсинга: фраза рекрутера превращается в готовые поисковые запросы по площадкам
и в JSON-фильтр подборки для внутренней ATS Candy. Тестовая версия, функциональность
в проработке.

## Устройство

Зависимостей нет и быть не должно: ни npm-пакетов, ни сборки, ни транспиляции. Это осознанное
ограничение — код должен запускаться на голом Node 18+. Внешний `require` или абсолютный путь
к файлу вне репозитория считается ошибкой.

- `server.js` — весь бэкенд: роутер, прокси к модели, подборки, метрики.
- `index.html` — весь фронтенд: справочники, разбор фразы, генерация запросов, интерфейс.
  Разделён комментариями-заголовками: `ДАННЫЕ`, `ПАРСИНГ`, `ГЕНЕРАЦИЯ`, `ПОДБОРКИ CANDY`,
  `РЕНДЕР`, `ФИЛЬТРЫ`, `AI-СЛОЙ`.
- `candy-json/` — движок подборок, основной путь.
- `candy-kb/` — выгруженные справочники Candy, источник правды для движка.
- `candy-prompt.md` — запасной путь подборок, включается при `CANDY_ENGINE=off`.
- `docs/` — документация для внешнего читателя.

## Проверки перед коммитом

```bash
node --check server.js       # синтаксис бэкенда
node candy-json/test.js      # тесты движка подборок
node candy-json/audit.js     # согласованность справочников
node server.js               # поднимается ли, порт 3000
```

Фронтенд проверяется вытаскиванием инлайн-скриптов из `index.html` и прогоном `node --check`
по каждому: обычный линтер тут не поможет, файл один.

## Правила

Репозиторий публичный. Ключи, пароли и токены только в переменных окружения, в коде их
значений быть не должно ни при каких условиях.

Документация в `docs/` пишется для внешнего читателя: без обращений к нему, без упоминания
конкретных команд и без разделов о том, чего в продукте нет.

Аккаунтов, тарифов и оплаты в этой версии нет. Код, который на них ссылается, — наследие
и подлежит удалению.

## Деплой

Coolify, ветка `main`, ручной Redeploy. Данные пишутся в `./data`, в контейнере это
смонтированный том. Полный список переменных — `docs/CONFIG.md`.
